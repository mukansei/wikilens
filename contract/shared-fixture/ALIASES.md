# 별칭 색인

다른 문서들이 각 페이지를 **실제로 부르는 이름**입니다. 자동 생성 — 직접 수정하지 마세요.

형식: `스페이스 | 제목 | 별칭 · 별칭 … | 인링크수 | 경로` — 한 줄이라 grep 결과에 스페이스와 경로가 항상 포함됩니다.

## 색인

DOCS | 루트 | 루트로 | 1 | mirror/pages/00/100.md
DOCS | 자식A | 자식 문서 | 1 | mirror/pages/00/200.md

## 별칭 없는 페이지

어느 문서도 링크하지 않았거나 제목 그대로만 링크된 페이지입니다.
검색으로만 도달 가능하므로 **고아 문서 후보**입니다.

DOCS | 고아B | (별칭 없음) | 0 | mirror/pages/00/300.md
