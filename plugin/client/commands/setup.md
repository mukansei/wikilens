WikiLens 서버판 설정을 진행하세요. 인자: `$ARGUMENTS` (비어 있을 수 있음)

로컬판과 달리 받아둘 볼트도 설치할 CLI 도 없습니다. **설정값이 둘뿐입니다.**

## 1. 지금 상태부터

```
python3 "${CLAUDE_PLUGIN_ROOT}/mcp/wikilens_mcp.py" --status
```

`SERVER=` 와 `USER=` 뒤의 괄호가 출처입니다(`env` · `config` · `default`).
**`default` 면 설정한 적이 없다는 뜻**이고, 그 상태에서는 로컬 주소를 보고 있어
검색이 전부 빕니다.

## 2. 값 두 개를 받으세요

| | |
|---|---|
| 서버 주소 | **운영자에게 받습니다.** 추측하지 마세요 (예: `http://wikilens.corp:8787`) |
| 본인 식별자 | 권한 확인에 쓰는 계정. 대개 조직 계정 이메일입니다 |

인자로 주어졌으면 그것을 쓰고, 없으면 사용자에게 물으세요. **비밀이 아닙니다** —
토큰이 아니므로 대신 입력해도 됩니다.

## 3. 기록

```
python3 "${CLAUDE_PLUGIN_ROOT}/mcp/wikilens_mcp.py" --configure --server <주소> --user <식별자>
```

`~/.wikilens/config.json` 에 **병합**해 씁니다 — 로컬판도 쓰는 파일이라 통째로
덮어쓰지 않습니다.

## 4. 확인하고 알리기

다시 `--status` 를 돌리세요. 남은 문제는 대부분 **운영자의 몫**이니 그대로 전달하세요:

- `ACL_USERS=0` → 운영자가 아직 아무도 등록하지 않았습니다. 사용자가 할 수 있는 일이 없습니다
- `INDEXED_DOCS=0` → 색인이 비었습니다. 재색인 요청
- `REACHABLE=no` → 주소가 맞다면 서버가 떠 있는지 문의

마지막으로 **재시작이 필요하다고 알리세요.** 설정은 MCP 프록시가 시작할 때 한 번만
읽으므로, 재시작 전에는 검색 도구가 여전히 옛 값으로 동작합니다.
