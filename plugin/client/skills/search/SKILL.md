# 팀 위키 검색

`wiki` MCP 도구 셋으로 팀의 Confluence를 검색합니다. 로컬에 파일이 없으므로
Read나 Grep 같은 파일 도구로는 접근할 수 없습니다.

## 반드시 search 부터

문서 제목과 사람들이 실제로 쓰는 말은 다릅니다. 제목이 `OAuth 2.0 인가 코드 흐름`인데
다들 "로그인 붙이는 법"이라고 부릅니다. 그 표현은 제목에도 본문에도 없습니다.

`search`는 다른 문서들이 각 페이지를 링크할 때 쓴 앵커 텍스트까지 색인하므로
그 격차를 메웁니다. 사용자의 표현을 **그대로** 넣으세요. 격식 있는 용어로
바꾸지 마세요 — 바꾸면 오히려 못 찾습니다.

```
search("로그인 붙이는 법")
→  * 1. [200000001] OAuth 2.0 인가 코드 흐름  (PLATFORM) rel=0.74
```

그 다음 `read(pageId)`로 본문을 가져옵니다.

### 다만 군더더기는 빼세요 — 낱말을 **바꾸지는 말고**

`어떻게`·`있나`·`보고싶은데`·`문서`·`거` 같은 말은 어느 문서에나 있어 후보만 늘립니다.
사용자가 고른 낱말은 그대로 두고 그런 말만 덜어내세요.

```
"결제 화면에서 어떤 api 타는지 정리된 거 있어?"
→  search("결제 화면 api")
```

실측(질의 30개): 문장을 그대로 넣으면 23건, 군더더기를 빼면 25건을 찾습니다.

**빼는 것이지 옮기는 것이 아닙니다.** `결제` 를 `payment` 로 고치면 앵커 색인이
메우려던 그 격차를 스스로 되돌리는 것이라 위 규칙을 어깁니다.

**남은 낱말이 전부 흔한 말이면**(`화면`·`주문`·`관리`처럼 위키 어디에나 나오는 말)
`search` 로는 잘 안 됩니다 — 정답이 수천 건과 같은 조건이 되어 뭐가 위로 올라올 이유가
없습니다. 그때는 `tree` 로 영역을 좁히거나, 사용자에게 특징적인 말 하나를 물어보세요.

## 도구 선택

| 상황 | 도구 |
|---|---|
| 개념·주제로 찾기 | **`search`** — 거의 항상 여기서 시작 |
| 본문 가져오기 | `read(pageId)` |
| 정확 일치가 필요 (식별자, 코드 조각, 정확한 문구) | `grep` |
| 이름은 모르고 영역(스페이스/카테고리)만 알 때, 위에서부터 훑기 | `tree` |

`grep`을 먼저 쓰지 마세요. 사용자가 쓴 표현이 문서 본문에 없어서 못 찾거나,
그 표현으로 *링크한* 다른 문서가 나옵니다.

**`grep` 에 여러 낱말을 그대로 넣지 마세요.** 매칭은 한 줄 안에서 일어나므로
"출장 신청 승인" 는 그 여덟 글자가 그 순서 그대로 붙어 있어야 합니다 — 사람이
쓰는 어순이 문서와 같을 이유가 없어 거의 항상 0건입니다. 낱말 사이를 `.*` 로 잇고
순서를 모르니 양방향으로 씁니다: `grep(pattern="출장.*승인|승인.*출장", regex=true)`.

`regex=true` 는 ripgrep 과 같은 RE2 문법입니다. 역참조(`\1`)와 전방탐색(`(?=)`)은
쓸 수 없고, 쓰면 0건이 아니라 이유가 옵니다. 대소문자는 어느 쪽이든 구분하지 않습니다.

`search`가 빈손이면 `tree`를 시도해보세요. 앵커 텍스트는 다른 문서가 링크를
걸어야 생기는데, 어디서도 링크되지 않은 '고아' 문서는 앵커가 없어 `search`로
못 찾습니다. `tree`는 링크가 아니라 Confluence 페이지 계층(상위 문서)을 따라가므로
그런 문서에도 닿습니다.

### 다 해봐도 없으면 — 거기서 멈추지 마세요

이 스킬은 위키를 뒤지는 방법이지 답할 수 있는 범위가 아닙니다. 위키에 없다고
사용자의 질문에 답할 수 없는 것이 아닙니다.

1. 위키에서 못 찾았다고 **분명히 말하세요.** 지어내지 마세요
2. 그리고 원래 질문에 **일반 지식으로 계속 답하세요**
3. 조직 고유 사정이라 일반 지식으로 못 답하면, 어디를 보면 될지 제안하세요

결과가 계속 비면 문서가 없는 게 아니라 설정이 막힌 것일 수 있습니다 —
아래 "도구가 오류를 내면"의 `--status` 를 돌려보세요. `ACL_USERS=0` 이면
색인이 멀쩡해도 **모든 검색이 빈손**입니다.

## 결과 읽는 법

- `*` = 어휘 검색과 학습 신호 양쪽에서 나옴. 가장 신뢰도 높음
- `S` = 다른 사람들의 탐색 이력에서만 나옴
- `rel=0.74` = 과거 세션에서 이 질의에 이 문서가 유용했던 정도

여러 후보가 나오면 `*` 표시와 `rel`이 높은 쪽이 대개 정본입니다.

## 도구가 오류를 내면

주소·식별자·서버·색인 중 무엇이 막혔는지는 진단 한 번으로 갈립니다. 추측하지 말고
실행한 뒤 그 출력을 근거로 안내하세요:

```
Bash: python3 "${CLAUDE_PLUGIN_ROOT}/mcp/wikilens_mcp.py" --status

Windows 에서 Bash 도구가 없으면(Git for Windows 미설치) PowerShell 로:
`python "$env:CLAUDE_PLUGIN_ROOT\mcp\wikilens_mcp.py" --status`
```

`ACL_USERS=0` 이면 문서가 없는 게 아니라 **운영자가 아직 아무도 등록하지 않은 것**이고,
사용자가 직접 할 수 있는 일이 없습니다 — 운영자에게 문의하라고 알려주세요.

## 주의

**권한 범위입니다.** 사용자가 볼 수 없는 문서는 검색 결과에도 나오지 않고
`read`도 "찾을 수 없음"으로 응답합니다. 못 찾았다고 보고할 때 이 점을 감안하세요.

**위키를 수정할 수 없습니다.** 읽기 전용입니다. 내용을 고쳐야 하면 Confluence에서
직접 하도록 안내하세요.
