# WikiLens 볼트 검색 (로컬판)

사내 Confluence가 로컬 마크다운으로 미러링돼 있습니다. 서버도 API 호출도 필요 없고,
평범한 파일 읽기와 grep만 씁니다.

## 1단계 — 볼트 위치부터 확인 (항상 먼저)

볼트는 지금 열려 있는 프로젝트 밖에 있습니다. 경로를 추측하지 말고 물어보세요:

```
Bash: python3 "${CLAUDE_PLUGIN_ROOT}/scripts/vault_status.py"
```

```
VAULT=/Users/me/wiki      ← 이 값을 아래 모든 경로 앞에 붙입니다
STATUS=ok                 ← 검색 가능 여부
PAGES=2378
AGE_DAYS=1
CLI=/path/to/wikilens     ← 갱신에만 필요. 비어 있어도 검색은 됩니다
CLI_SOURCE=/path/to/cli
CREDS=file                ← file | shell | none
STRAY=0
OTHER=                    ← 비어 있어야 정상. 값이 있으면 서버판도 켜져 있습니다
```

**`OTHER` 에 값이 있으면 서버판도 켜져 있습니다.** 그 MCP 도구가 실제로 보인다면
그쪽으로 답하세요 — 이 스킬은 서버가 없을 때를 위한 것입니다. 답을 마친 뒤 한 번만
알리세요: *"두 판이 모두 켜져 있습니다. 하나만 쓰려면
`claude plugin disable wikilens-local@wikilens` 로 끌 수 있습니다."*
직접 끄지는 마세요.

**`STATUS`가 `ok` 또는 `stale`이면 곧바로 2단계로 갑니다.** 그게 거의 항상입니다.
`stale`이면 답을 마친 뒤 *"볼트가 N일 됐습니다, 갱신할까요?"* 를 덧붙이세요 —
단 `CREDS=none` 이거나 `CLI=` 가 비어 있으면 갱신이 불가능하니, 갱신을 제안하는
대신 `/wikilens-local:setup` 이 필요하다고 알리세요. **되지도 않을 일을 제안하지 마세요.**

그 밖의 값(`missing`·`unsynced`·`unbuilt`)은 볼트를 아직 쓸 수 없다는 뜻입니다.
**셋 다 똑같이 처리하세요:**

1. 사용자의 원래 질문에 **일반 지식으로 먼저 답하세요.** 설정이 안 됐다고 대화를
   멈춰 세우지 마세요.
2. 그런 다음 한 줄로 제안하세요 — *"사내 위키에서도 찾아보려면 설정이 필요합니다.
   지금 할까요? (약 5분, Confluence에서 문서를 받아옵니다)"*
3. 승낙하면 `${CLAUDE_PLUGIN_ROOT}/references/setup.md` 를 읽고
   그대로 따릅니다. 절차를 지어내지 마세요.
4. 거절하거나 답이 없으면 **이 세션에서 다시 꺼내지 마세요.**

## 2단계 — 반드시 `ALIASES.md` 부터

문서 제목과 사람들이 실제로 쓰는 말은 다릅니다. 제목이 `OAuth 2.0 인가 코드 흐름`인데
다들 "로그인 붙이는 법"이라고 부릅니다. 본문에도 제목에도 그 표현은 없습니다.

`ALIASES.md`는 다른 문서들이 각 페이지를 뭐라고 부르며 링크했는지를 모은 색인입니다.
이 격차를 메우는 유일한 수단이므로 여기서 시작하세요.

```
Grep(pattern="로그인", path="<VAULT>/ALIASES.md", output_mode="content", -i=true)
```

각 줄은 `스페이스 | 제목 | 별칭 · 별칭 … | 인링크수 | 경로` 형식입니다:

```
PLATFORM | OAuth 2.0 인가 코드 흐름 | 로그인 붙이는 법 · 인증 붙이기 | 2 | mirror/pages/01/200000001.md
```

**마지막 필드가 볼트 루트 기준 상대경로입니다.** 앞에 `<VAULT>/`를 붙여야 읽힙니다:

```
Read("<VAULT>/mirror/pages/01/200000001.md")
```

**첫 필드는 스페이스입니다.** 여러 스페이스를 싱크한 볼트면 같은 낱말이 여러 영역에서
걸리므로, 사용자가 영역을 말했다면 그걸로 좁히세요 — `Grep(pattern="PLATFORM.*로그인", -i=true)`.
`TREE.md` 도 줄마다 `[스페이스]` 를 답니다.

## 검색 순서

1. `ALIASES.md` grep — 사용자 어휘로 찾기. 대부분 여기서 끝납니다
2. 영역만 알고 이름을 모르면 `TREE.md` — `Grep(path="<VAULT>/TREE.md", -i=true)` 로 위에서부터 훑기
3. `<VAULT>/mirror/pages/` 전체 grep — 그래도 없으면 본문에서 찾기
4. 인링크 수 참고 — 여러 후보가 나오면 인링크가 많은 쪽이 대개 정본입니다

### 여러 단어로 물으면 **그대로 grep 하지 마세요**

`Grep` 은 정규식을 받지만 매칭은 **한 줄 안에서** 일어납니다. "출장 신청 승인" 를
그대로 넣으면 그 여덟 글자가 한 줄에 그 순서 그대로 붙어 있어야 하므로 거의 항상
0건입니다. 사람이 쓰는 어순과 문서 제목의 어순이 같을 이유가 없습니다.
실측: 그대로 넣으면 0건, 낱말을 이으면 3건.

**낱말 사이를 `.*` 로 잇고, 순서를 모르니 양방향을 씁니다:**

```
Grep(pattern="출장.*승인|승인.*출장", path="<VAULT>/ALIASES.md", output_mode="content", -i=true)
```

정규식이 부담스러우면 낱말을 하나씩 넣고 양쪽에 다 나온 줄을 고르세요 — 결과는
같습니다. 낱말이 셋 이상이면 흔한 말(정책·관리·문서)을 빼고 특징적인 둘로 좁힙니다.

교집합이 0건이면 한 낱말씩 다시 보세요. 그래도 없을 때 2번(`TREE.md`)입니다.

**1번을 건너뛰면 조용히 틀린 답을 줍니다.** 본문 grep은 그 표현으로 *링크한* 페이지를
찾아주지, 찾으려는 문서를 주지 않습니다. "로그인"으로 본문을 뒤지면 OAuth 문서가 아니라
그것을 "로그인 붙이는 법"이라고 부르며 링크한 온보딩 문서가 나옵니다.

### `-i=true` 를 빼지 마세요

`Grep` 은 ripgrep 이라 기본이 대소문자 구분입니다(실측: `acme` 로 `Acme` 를 못
찾습니다 — 실볼트 `ALIASES.md` 에서 `acme` 가 17건 대 48건입니다). 이 위키는 한국어 문서에 영문 고유명사·식별자가 섞여 있고, 사용자가 그것을
어떤 표기로 칠지는 알 수 없습니다 — `acme`·`Acme`·`ACME` 가 다 나옵니다.
구분한 채로 두면 **결과가 있는데 0건으로 보입니다.**

서버판도 같은 이유로 대소문자를 구분하지 않습니다. 한쪽만 바꾸면 판을 옮긴 사용자가
같은 질의에 다른 답을 받습니다 — `shared_contract.sh` 가 둘이 어긋나는지 검사합니다.

### 다 해봐도 없으면 — 거기서 멈추지 마세요

이 스킬은 볼트를 뒤지는 방법이지 답할 수 있는 범위가 아닙니다. 볼트에 없다고
사용자의 질문에 답할 수 없는 것이 아닙니다.

1. 볼트에서 못 찾았다고 **분명히 말하세요.** 지어내지 마세요
2. 그리고 원래 질문에 **일반 지식으로 계속 답하세요**
3. 사내 고유 사정이라 일반 지식으로 못 답하면, 어디를 보면 될지 제안하세요
   (Confluence 직접 검색, 담당 팀 문의 등)

볼트가 사용자 권한 범위라는 점도 감안하세요 — "볼트에 없다"와 "회사에 그런 문서가
없다"는 다릅니다.

## 고아 문서 — `TREE.md` 로만 닿습니다

`ALIASES.md`는 다른 문서가 링크를 걸어야 별칭이 생깁니다. 어디서도 링크되지 않은
'고아' 문서는 별칭이 없어 여기서 못 찾습니다. 이름은 모르고 영역(스페이스/카테고리)만
알 때, 그리고 "링크 안 된 문서 목록"을 물을 때가 `TREE.md` 차례입니다.

```
Grep(pattern="영업", path="<VAULT>/TREE.md", output_mode="content", -i=true)
```

`ALIASES.md` 끝의 "별칭 없는 페이지" 목록이 그 고아들입니다 — 위키 정리에 관심을
보이는 사용자에게 유용합니다.

## 볼트 구조

```
<VAULT>/ALIASES.md                별칭 색인. 검색 시작점
<VAULT>/TREE.md                   계층 목차. 별칭 없는 문서는 여기서
<VAULT>/mirror/pages/…/{id}.md    마크다운. 경로는 ALIASES.md 에 적힌 것을 쓰세요
<VAULT>/mirror/raw/…/{id}.xhtml   Confluence 원본. 매크로가 필요할 때만
<VAULT>/derived/anchors.jsonl     별칭 원자료. 프로그램용
```

각 페이지의 front matter 에 `id`·`title`·`space`·`version` 이 있습니다.
**제목이 아니라 `id`가 식별자입니다** — 제목은 바뀝니다.

## 주의사항

**볼트는 읽기 전용입니다.** 이 파일들은 Confluence에서 자동 생성되며 다음 싱크에
덮어써집니다. 수정하지 마세요. 위키 내용을 고쳐야 하면 Confluence에서 직접 하도록
사용자에게 안내하세요.

**볼트는 사용자 권한 범위입니다.** 본인 토큰으로 싱크되므로 사용자가 볼 수 없는
문서는 애초에 없습니다. 없는 문서를 못 찾았다고 보고할 때 이 점을 감안하세요.

**볼트는 회수되지 않는 사본입니다.** 권한이 바뀌거나 팀을 떠나면 볼트를 직접 지워야
합니다 — 서버판과 달리 로컬판은 자동 취소가 없습니다.

**갱신은 `/wikilens-local:sync`.** `AGE_DAYS`가 크고 최신 정보가 중요하면 제안하세요.
사용자가 커맨드 이름을 몰라도 되게, 제안한 뒤 승낙하면 직접 실행해 주세요.

**`STRAY`가 0보다 크면** 볼트에 샤딩 규칙을 벗어난 파일이 있습니다(경로는 `STRAY_PATH=`
줄에). 검색은 그대로 하세요. 다만 `sync`는 이 파일들을 **영원히 못 지우므로**(삭제
청소가 아는 페이지 ID만 훑습니다) 답을 마친 뒤 한 번 알리고 `rm`을 제안하세요.
직접 지우지는 마세요.
