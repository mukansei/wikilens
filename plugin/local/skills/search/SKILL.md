# WikiLens 볼트 검색 (로컬판)

사내 Confluence가 로컬 마크다운으로 미러링돼 있습니다. 서버도 API 호출도 필요 없고,
평범한 파일 읽기와 grep만 씁니다.

## 1단계 — 볼트 위치부터 확인 (항상 먼저)

볼트는 지금 열려 있는 프로젝트 **밖**에 있습니다. 경로를 추측하지 말고 물어보세요:

```
Bash: python3 "${CLAUDE_PLUGIN_ROOT}/scripts/vault_status.py"
```

```
VAULT=/Users/me/wiki      ← 이 값을 아래 모든 경로 앞에 붙입니다
STATUS=ok
PAGES=2378
AGE_DAYS=1
STRAY=0
```

`STATUS`에 따라:

| STATUS | 할 일 |
|---|---|
| `ok` | 그대로 검색 |
| `stale` | 검색하되, 답할 때 "볼트가 N일 됐다"를 함께 알림 |
| `unbuilt` | `wikilens --root <VAULT> build` 를 제안 |
| `unsynced` | `/wikilens-local:sync` 를 제안 |
| `missing` | `references/setup.md` 를 읽고 설정을 안내 |

**`missing`일 때 주의:** 안내는 **이 세션에서 한 번만** 하세요. 그리고 사용자의 원래
질문에는 일반 지식으로 계속 답하세요 — 설정이 안 됐다고 대화를 멈춰 세우면 안 됩니다.

**`STRAY`가 0보다 크면** 샤딩 규칙을 벗어난 파일이 있다는 뜻입니다(`STRAY_PATH=` 줄에
경로가 나옵니다). 검색은 그대로 하세요 — 막지 않습니다. 다만 `sync`는 이 파일들을
**영원히 못 지우므로**(삭제 청소가 아는 페이지 ID만 훑습니다) 검색을 마친 뒤 한 번
알리고 `rm` 을 제안하세요. 직접 지우지는 마세요.

## 2단계 — 반드시 `ALIASES.md` 부터

문서 제목과 사람들이 실제로 쓰는 말은 다릅니다. 제목이 `OAuth 2.0 인가 코드 흐름`인데
다들 "로그인 붙이는 법"이라고 부릅니다. 본문에도 제목에도 그 표현은 없습니다.

`ALIASES.md`는 **다른 문서들이 각 페이지를 뭐라고 부르며 링크했는지**를 모은 색인입니다.
이 격차를 메우는 유일한 수단이므로 여기서 시작하세요.

```
Grep(pattern="로그인", path="<VAULT>/ALIASES.md", output_mode="content")
```

각 줄은 `제목 | 별칭 · 별칭 … | 인링크수 | 경로` 형식입니다:

```
OAuth 2.0 인가 코드 흐름 | 로그인 붙이는 법 · 인증 붙이기 | 2 | mirror/pages/20/00/200000001.md
```

**네 번째 필드는 볼트 루트 기준 상대경로입니다.** 앞에 `<VAULT>/`를 붙여야 읽힙니다:

```
Read("<VAULT>/mirror/pages/20/00/200000001.md")
```

## 검색 순서

1. **`ALIASES.md` grep** — 사용자 어휘로 찾기. 대부분 여기서 끝납니다
2. **영역만 알고 이름을 모르면 `TREE.md`** — `Grep(path="<VAULT>/TREE.md")` 로 위에서부터 훑기
3. **`<VAULT>/mirror/pages/` 전체 grep** — 그래도 없으면 본문에서 찾기
4. **인링크 수 참고** — 여러 후보가 나오면 인링크가 많은 쪽이 대개 정본입니다

**1번을 건너뛰면 조용히 틀린 답을 줍니다.** 본문 grep은 그 표현으로 *링크한* 페이지를
찾아주지, 찾으려는 문서를 주지 않습니다. "로그인"으로 본문을 뒤지면 OAuth 문서가 아니라
그것을 "로그인 붙이는 법"이라고 부르며 링크한 온보딩 문서가 나옵니다.

## `ALIASES.md`에서 못 찾으면 `TREE.md`

`ALIASES.md`는 다른 문서가 **링크를 걸어야** 별칭이 생깁니다. 어디서도 링크되지 않은
'고아' 문서는 별칭이 없어 여기서 못 찾습니다. 정확한 이름은 모르지만 어느 영역
(스페이스/카테고리)에 있는지는 알 때 `TREE.md`(부모-자식 계층 목차)를 훑어보세요.

```
Grep(pattern="영업", path="<VAULT>/TREE.md", output_mode="content")
```

## 볼트 구조

```
<VAULT>/ALIASES.md                        별칭 색인. 검색 시작점
<VAULT>/TREE.md                           계층 목차. 별칭 없는 문서는 여기서
<VAULT>/mirror/pages/{sh}/{ard}/{id}.md   마크다운. 사람이 읽는 본문
<VAULT>/mirror/raw/{sh}/{ard}/{id}.xhtml  Confluence 원본. 매크로가 필요할 때만
<VAULT>/derived/anchors.jsonl             별칭 원자료. 프로그램용
```

`{sh}/{ard}`는 페이지 ID 앞 4자리입니다. 경로를 직접 계산하지 말고 `ALIASES.md`에
적힌 경로를 쓰세요.

각 페이지 파일의 front matter에 권위 있는 식별자가 있습니다:

```yaml
id: "200000001"
title: OAuth 2.0 인가 코드 흐름
space: PLATFORM
version: 47
```

**제목이 아니라 `id`가 식별자입니다.** 제목은 바뀝니다.

## 주의사항

**볼트는 읽기 전용입니다.** 이 파일들은 Confluence에서 자동 생성되며 다음 싱크에
덮어써집니다. 수정하지 마세요. 위키 내용을 고쳐야 하면 Confluence에서 직접 하도록
사용자에게 안내하세요.

**볼트는 사용자 권한 범위입니다.** 본인 토큰으로 싱크되므로 사용자가 볼 수 없는
문서는 애초에 없습니다. 없는 문서를 못 찾았다고 보고할 때 이 점을 감안하세요.

**볼트는 회수되지 않는 사본입니다.** 권한이 바뀌거나 팀을 떠나면 볼트를 직접 지워야
합니다 — 서버판과 달리 로컬판은 자동 취소가 없습니다.

**갱신은 `/wikilens-local:sync`.** `AGE_DAYS`가 크고 최신 정보가 중요하면 제안하세요.

## 고아 문서

`ALIASES.md` 끝의 "별칭 없는 페이지"는 **어느 문서도 링크하지 않는** 페이지입니다.
검색으로만 도달 가능하다는 뜻이라, 사용자가 위키 정리에 관심을 보이면 유용한 목록입니다.
이런 문서를 찾아줘야 할 때는 `ALIASES.md`로는 안 되니 `TREE.md`로 찾으세요.
