# WikiLens 볼트 검색

사내 Confluence가 로컬 마크다운으로 미러링돼 있습니다. 서버도 API 호출도 필요 없고,
평범한 파일 읽기와 grep만 씁니다.

## 반드시 ALIASES.md 부터 찾으세요

문서 제목과 사람들이 실제로 쓰는 말은 다릅니다. 제목이 `OAuth 2.0 인가 코드 흐름`인데
다들 "로그인 붙이는 법"이라고 부릅니다. 본문에도 제목에도 그 표현은 없습니다.

`ALIASES.md`는 **다른 문서들이 각 페이지를 뭐라고 부르며 링크했는지**를 모은 색인입니다.
이 격차를 메우는 유일한 수단이므로 여기서 시작하세요.

```
Grep(pattern="로그인", path="ALIASES.md", output_mode="content")
```

각 줄이 `제목 | 별칭 · 별칭 … | 인링크수 | 경로` 형식이라 **컨텍스트 플래그 없이도
경로가 함께 나옵니다**:

```
OAuth 2.0 인가 코드 흐름 | 로그인 붙이는 법 · 인증 붙이기 | 2 | mirror/pages/20/00/200000001.md
```

그 경로를 그대로 Read 하면 됩니다.

## 검색 순서

1. **`ALIASES.md` grep** — 사용자 어휘로 찾기. 대부분 여기서 끝납니다
2. **영역만 알고 이름을 모르면 `TREE.md`** — 위에서부터 훑기
3. **`mirror/pages/` 전체 grep** — 그래도 없으면 본문에서 찾기
4. **인링크 수 참고** — 여러 후보가 나오면 인링크가 많은 쪽이 대개 정본입니다

**1번을 건너뛰면 조용히 틀린 답을 줍니다.** 본문 grep은 그 표현으로 *링크한* 페이지를
찾아주지, 찾으려는 문서를 주지 않습니다. "로그인"으로 본문을 뒤지면 OAuth 문서가 아니라
그것을 "로그인 붙이는 법"이라고 부르며 링크한 온보딩 문서가 나옵니다.

## ALIASES.md에서 못 찾으면 TREE.md

`ALIASES.md`는 다른 문서가 **링크를 걸어야** 별칭이 생깁니다. 어디서도 링크되지
않은 '고아' 문서는 별칭이 없어 여기서 못 찾습니다. 정확한 이름은 모르지만 어느
영역(스페이스/카테고리)에 있는지는 알 때, `TREE.md`(부모-자식 계층 목차)를
위에서부터 훑어보세요.

```
Grep(pattern="영업", path="TREE.md", output_mode="content")
```

파일이 커서 한 번에 다 보기 부담스러우면 관심 있는 상위 항목만 grep으로 걸러
그 아래 들여쓰기 자식들을 따라가면 됩니다.

## 볼트 구조

```
ALIASES.md                        별칭 색인. 검색 시작점
TREE.md                           계층 목차. 별칭 없는 문서는 여기서
mirror/pages/{sh}/{ard}/{id}.md   마크다운. 사람이 읽는 본문
mirror/raw/{sh}/{ard}/{id}.xhtml  Confluence 원본. 매크로가 필요할 때만
derived/anchors.jsonl             별칭 원자료. 프로그램용
```

`{sh}/{ard}`는 페이지 ID 앞 4자리입니다. 경로를 직접 계산하지 말고
`ALIASES.md`에 적힌 경로를 쓰세요.

각 페이지 파일의 front matter에 권위 있는 식별자가 있습니다:

```yaml
id: "200000001"
title: OAuth 2.0 인가 코드 흐름
space: PLATFORM
version: 47
```

**제목이 아니라 `id`가 식별자입니다.** 제목은 바뀝니다.

## 주의사항

**볼트는 읽기 전용입니다.** 이 파일들은 Confluence에서 자동 생성되며 다음 싱크에
덮어써집니다. 수정하지 마세요. 위키 내용을 고쳐야 하면 Confluence에서 직접 하도록
사용자에게 안내하세요.

**볼트는 사용자 권한 범위입니다.** 개인 토큰으로 싱크되므로 사용자가 볼 수 없는
문서는 애초에 없습니다. 없는 문서를 못 찾았다고 보고할 때 이 점을 감안하세요.

**볼트가 낡았을 수 있습니다.** `mirror/.sync-state.json`의 `cursor`가 마지막 싱크
시각입니다. 오래됐고 최신 정보가 중요하면 `wikilens sync --space KEY` 실행을 제안하세요.

## 고아 문서

`ALIASES.md` 끝의 "별칭 없는 페이지"는 **어느 문서도 링크하지 않는** 페이지입니다.
검색으로만 도달 가능하다는 뜻이라, 사용자가 위키 정리에 관심을 보이면 유용한 목록입니다.
이런 문서를 찾아줘야 할 때는 `ALIASES.md`로는 안 되니 `TREE.md`로 찾으세요.
