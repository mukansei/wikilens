# WikiLens 로컬판 — 사용 안내

사내 Confluence를 **내 노트북에** 미러링해두고, Claude Code가 그걸 뒤져 문서를 찾아줍니다.
서버가 필요 없고 오프라인에서도 됩니다.

## 왜 그냥 검색과 다른가

문서 제목과 사람들이 실제로 쓰는 말이 다르기 때문입니다. 제목이
`OAuth 2.0 인가 코드 흐름`인데 다들 "로그인 붙이는 법"이라고 부릅니다 —
그 표현은 제목에도 본문에도 없습니다.

WikiLens는 **다른 문서들이 각 페이지를 링크할 때 쓴 표현**(앵커 텍스트)을 따로 모아둡니다.
그래서 사내 은어로 물어도 찾습니다.

## 설치

```
/plugin marketplace add <저장소 경로 또는 git URL>
/plugin install wikilens-local@wikilens-tools
/reload-plugins
```

이어서 설정을 시작합니다:

```
/wikilens-local:setup
```

Claude가 순서대로 안내합니다. **각 단계는 물어보고 진행하니** 그냥 따라가면 됩니다.

### 미리 준비할 것

| | |
|---|---|
| `CONFLUENCE_URL` | 예: `https://wiki.mycompany.com` |
| 인증 토큰 | 대개 **개인 액세스 토큰(PAT)** 하나면 됩니다 |

셸에 export 해두세요:

```bash
export CONFLUENCE_URL=https://wiki.mycompany.com
export CONFLUENCE_TOKEN=<발급받은 PAT>
```

SSO를 쓰는 회사여도 대개 PAT가 따로 동작합니다. 안 되면 setup이 다른 방식
(Cloud API 토큰 · 사내 IAM · 리버스 프록시)을 안내합니다.

> **Coway(`wiki.coway.com`)라면** `export CONFLUENCE_PREFIX=""` 도 함께 필요합니다.
> 사내 게이트웨이 구성 때문에 자동 판별이 잘못된 주소를 고릅니다.

### 첫 싱크는 시간이 걸립니다

스페이스 하나에 수천 페이지면 **수 분**, 수십 MB를 받습니다. 한 번만 하면 되고,
중단돼도 다음에 이어받습니다.

## 쓰는 법

따로 명령이 없습니다. **그냥 물어보세요:**

- "우리 회사 배포 절차 문서 어디 있어?"
- "출장 신청 승인 관련 문서 찾아줘"
- "SDK 접속 방법 알려줘"

Claude가 알아서 볼트를 뒤집니다. 사내 은어나 축약어를 그대로 써도 됩니다 —
오히려 격식 있는 용어로 바꾸면 못 찾을 수 있습니다.

### 갱신

```
/wikilens-local:sync
```

위키가 바뀌어도 볼트는 그대로이므로 가끔 돌려주세요. 볼트가 오래되면 Claude가
"N일 됐다"고 함께 알려줍니다.

## 알아둘 것

**볼 수 있는 문서만 들어옵니다.** 본인 토큰으로 받아오므로, Confluence에서 권한이 없는
문서는 애초에 볼트에 없습니다. Claude가 "못 찾았다"고 할 때 이 점을 감안하세요.

**볼트는 읽기 전용입니다.** WikiLens는 위키에 절대 쓰지 않습니다. 내용을 고쳐야 하면
Confluence에서 직접 하세요. 볼트 파일을 고쳐도 다음 싱크에 덮어써집니다.

**볼트는 자동으로 회수되지 않습니다.** 부서를 옮기거나 권한이 바뀌거나 팀을 떠날 때
**직접 지워야 합니다:**

```bash
rm -rf ~/.wikilens        # 볼트 위치를 바꿨다면 그 경로
```

## 문제가 생기면

| 증상 | 확인 |
|---|---|
| 검색 결과가 계속 비어 있음 | `/wikilens-local:sync` 로 볼트가 있는지 확인 |
| "볼트를 찾을 수 없다" | `/wikilens-local:setup` 을 다시 실행 |
| 프로젝트마다 읽기 승인을 물음 | setup 마지막의 권한 등록을 건너뛴 경우입니다. 다시 실행하세요 |
| 문서는 있는데 안 나옴 | 링크가 하나도 없는 '고아' 문서일 수 있습니다. "OO 영역 문서 목록 보여줘" 처럼 물으면 계층으로 찾습니다 |

현재 상태를 직접 보려면:

```bash
python3 ~/.claude/plugins/cache/wikilens-tools/wikilens-local/*/scripts/vault_status.py
```

## 서버판과 헷갈리지 마세요

`wikilens`(서버판)와 **둘 중 하나만** 설치하세요. 둘 다 깔면 Claude가 어느 쪽을 쓸지
헷갈립니다.

| | 로컬판 (이것) | 서버판 |
|---|---|---|
| 준비 | 각자 싱크 (수 분) | 관리자가 서버 운영 |
| 검색 | 파일 grep | BM25 + 형태소 분석 + 학습 |
| 오프라인 | 가능 | 불가 |
| 권한 | 내 토큰 = 내 범위 | 서버가 요청마다 확인 |

혼자 쓰거나 소규모 팀이면 로컬판, 인원이 많으면 서버판이 맞습니다.
