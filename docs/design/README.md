# 실행 전 설계

**측정을 돌리기 전에 적은 것**입니다. 무엇을 왜 재는지, 어떻게 재는지, **무엇이
나올 것으로 보는지**, 그리고 판정 기준을 실행 **전에** 고정합니다.

결과를 보고 기준을 정하면 유리한 쪽으로 읽게 됩니다. 이 저장소는 그것으로 한 번
데였고(G08 재현 실패를 정직하게 읽을 수 있었던 것이 이 습관 덕입니다), 그 뒤로
예측을 먼저 적습니다.

## 왜 저장소에 두나

실험 기록이 *"실행 전에 예측을 못박았다"* 라고 말할 때, **그 파일이 없으면 검증할
수 없는 주장**이 됩니다. clone 한 사람이 확인할 수 있어야 합니다.

한동안 세션 작업본(`scratchpad/`)에 두었는데 추적되지 않아 사라졌습니다 —
`experiment-2026-08-19-learning.md` 와 `experiment-2026-08-21-poison.md` 가
그렇게 근거 파일을 잃었고, 본문에 "안 남았다" 고 적어 두었습니다.

## 읽는 법

**결과는 여기 없습니다.** 짝이 되는 `docs/experiment-*.md` 가 결과이고, 예측이
맞았는지 틀렸는지도 거기 있습니다. **틀린 예측을 고쳐 적지 않습니다** — 틀렸다는
사실이 대개 결과보다 값어치가 큽니다.

```
docs/design/design-2026-08-23-anchor.md   →  docs/experiment-2026-08-23-anchor.md
docs/design/design-2026-08-26-title-dup.md →  docs/experiment-2026-08-26-title-dup-anchor.md
```

`design-2026-08-26-stopword-and-tree.md` 는 짝이 둘로 갈렸습니다 — 무의미 앵커
거르기와 계층 층이 한 파일에 있었고, 결과는 앵커 실험 기록에 함께 적혔습니다.
