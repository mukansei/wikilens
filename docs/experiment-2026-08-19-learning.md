# 학습 레이어와 서버판이 실제로 일하는가 (2026-08-19)

**형상** `f74ec58f` · 코퍼스 13,474건(문자 집합 필터 켬) · 서버 이미지 `bb4e04f80e82`

두 질문을 나눠 잰다. **난이도가 다르다** — 서버판 쪽은 이미 데이터가 있고, 학습
레이어는 이 저장소가 "측정된 바 없음" 이라 적어둔 자리다.

**실행 전에 판정 기준을 못박았다**(`scratchpad/design.md`). 결과를 보고 정하면
유리한 쪽으로 읽게 된다 — G08 때 그렇게 해서 재현 실패를 정직하게 읽을 수 있었다.

## ① 학습이 발동하는가 — 증명됨 ($0)

`bench/learn.py --pattern repeat --groups G01 G04 G09 --reps 4`. 모델을 안 쓰고
HTTP 세 번(`search`→`read`→`session/end`)으로 궤적을 쌓아 순위 변화를 본다.

```
  G01 어휘 밖     r0 밖 · r1 밖 · r2 밖 · r3 밖        끝까지 힌트 0
  G04 어휘 1위    r0 1위 · r1 1위(힌트) · …            이미 1위
  G09 어휘 14위   r0 밖 · r1 밖 · r2 1위 · r3 1위      ← 밖 → 1위
```

**G09 가 이 층이 일한다는 결정적 증거다.** 어휘로 14위인 문서가 두 번 관측 뒤
1위로 올라온다. 궤적 12건 · 포스팅 항 17개 · 서빙 5 · 거부 0.

### 그런데 같은 표가 이 층의 한계도 말한다

    어휘 1위    학습이 없어도 찾는다        → 학습이 불필요
    어휘 14위   두 번 관측이면 1위          → **여기가 유일하게 의미 있는 띠**
    어휘 밖     7관측 필요, 끝까지 0        → 학습이 안 닿는다

**학습이 가장 필요한 문서(어휘 밖)에서 가장 늦게, 또는 아예 안 발동한다.**
사전확률이 어휘 점수라서 그렇다 — 어휘가 못 찾는 문서는 사전확률이 낮고, 낮으면
더 많은 관측을 요구한다. 설계상 그렇게 되어 있고 D23 이 그 근거다.

## ② 모델이 그 힌트로 덜 헤매는가 — 증명됨 ($4.24)

같은 질의(G09 q0)를 학습 없음 6세션 · 학습 있음 7세션으로 돌렸다. 나머지는 전부
같다 — 같은 코퍼스·이미지·모델.

**대조군을 깨끗하게 만드는 데 장치가 필요했다.** 세션마다 서버를 초기화한다
(`scratchpad/cold.sh`) — 안 그러면 앞 세션의 궤적이 뒤 세션을 학습 있음으로 만든다.
실험군은 반대로 `learn.py` 로 궤적을 먼저 쌓았다($0) — 안 그러면 초반 세션이
학습을 만드는 동안 힌트를 못 받아 **실험군 안에 대조군이 섞인다**(기존
`agent.jsonl` 37세션 중 힌트를 받은 것이 2개뿐이었던 이유가 그것이다).

배선 확인: 대조군 힌트 `[0,0,0,0,0,0]` · 실험군 `[1,1,1,1,1,1,1]`.

```
                  학습 없음      학습 있음
  적중              5/6          7/7
  턴 중앙             7            5
  토큰 중앙        245,784      184,071
  비용 중앙          $0.35        $0.18
```

**턴 분포가 전혀 겹치지 않는다.**

```
  학습 없음  [7, 7, 7, 7, 7, 9]     평균 7.33
  학습 있음  [4, 4, 4, 5, 6, 6, 6]  평균 5.00     최대 6 < 최소 7
```

순열검정 **p=0.0006**(단측). 앞선 1세션을 빼고 이번 회차 6개만 써도 p=0.0011 이라
결론이 안 바뀐다. 토큰은 **29% 감소**(260k → 184k).

**적중률로는 결론이 안 난다** — 5/6 → 7/7 이지만 Fisher p=0.462 다. 대조군이 이미
천장에 붙어 있었다. 실행 전에 "부 지표인 턴·토큰이 결론을 낼 것" 이라고 적어둔
그대로가 됐다 — **연속값이라 6개씩으로도 분포가 보인다.**

### 무엇이 줄었나

정답이 14위에서 1위로 올라오면 모델이 **덜 뒤진다.** 대조군은 `search` 뒤에
후보를 여럿 열어보고 고르는데(7턴), 실험군은 1위를 열고 확인하면 끝난다(4~5턴).
비용으로는 세션당 $0.35 → $0.18 이다.

## 서버판 실효성 — 데이터는 있으나 해석에 주의

### 좁히기 (30질의 · $0)

```
  A 원시grep   상위10  0/30 · 못 찾음 12
  B 로컬판      상위10  6/30 · 못 찾음 19
  C 서버판      상위10 16/30 · 못 찾음 11
```

서버판이 로컬판의 **2.7배**를 상위 10 안에 넣는다. 이것이 형태소 분석 + 앵커
가중 + BM25 의 값어치다.

### 에이전트 (agent.jsonl · cold 7세션씩 · 같은 질의)

```
  A 원시grep   적중 7/7 · 턴 24 · 991k토큰 · $8.30
  B 로컬판      적중 7/7 · 턴  9 · 304k토큰 · $3.94
  C 서버판      적중 6/7 · 턴  6 · 181k토큰 · $3.25
```

**적중률로는 서버판이 오히려 낮다(6/7 vs 7/7).** n=7 이라 차이가 아니다.
읽을 수 있는 것은 **비용**이다 — 서버판이 원시 grep 의 5.5배 싸고 턴이 1/4 이다.

**해석 주의:** 이 세 케이스는 같은 질의를 봤지만 세션 수가 7뿐이고, 적중률이
전부 6~7/7 이라 **천장에 붙어 있다.** 여기서 갈리는 것은 정답 여부가 아니라
거기 도달하는 비용이다.

## 이 실험이 증명하지 못하는 것 (미리 적는다)

- **`learn.py` 는 정답을 읽어서 학습시킨다.** 실사용은 엉뚱한 문서도 읽는다.
  그래서 ①은 **천장 측정**이다 — 여기서 안 오르면 볼 것이 없지만, 올라도
  실사용이 그렇다는 뜻은 아니다.
- **같은 표현이 반복될 때만 작동한다.** `transfer`(q0 로 학습 후 다른 표현으로
  시험)는 2026-08-13 에 **끝까지 0** 이었다. 자연어 질의는 매번 표현이 다르다.
- **G09 는 가장 유리한 조건으로 고른 그룹이다.** 어휘 14위라는 위치가 학습이
  의미 있는 유일한 띠에 정확히 들어간다.
